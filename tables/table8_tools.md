# Table 8 — Software Components and Reproducibility Records

Tools are listed by pipeline stage. Availability does not imply that a pipeline has been reproduced.

| Stage | Tool | Inputs and outputs | Role | License | Record |
|---|---|---|---|---|---|
| Registration | SimpleITK | Images and masks; aligned images and transforms. | Align CT-MRI pairs and resample onto a shared physical grid. | Apache 2.0 | Save transform direction, reference grid, interpolation, optimizer settings and registration checks. |
| Registration | ANTs | Image volumes; affine transforms and deformation fields. | Provide an alternative registration and MRI bias-correction component. | Apache 2.0 | Save command lines, masks, transform order, similarity metric and parameter files. |
| ROI and display | 3D Slicer | Volumes, labels and transforms; scenes, masks and views. | Inspect alignment, edit ROIs and review source images alongside fused outputs. | BSD-style Slicer license | Save scene, extension versions, ROI edits, display windows and overlay settings; viewing alone is not clinical validation. |
| Data preparation | MONAI | Images and metadata; transformed tensors and batches. | Compose medical-image loading, caching and synchronized spatial transforms. | Apache 2.0 | Save dataset manifest, transform order, reader options, channel order, spacing, normalization and seeds. |
| Data preparation | TorchIO | Subject images and labels; transformed volumes and patches. | Prepare corresponding 3D inputs and apply shared spatial augmentation. | Apache 2.0 | Save subject definitions, sampling policy, transform parameters and random states; verify paired geometry. |
| Algorithm development | MATLAB Image Processing Toolbox | Arrays and images; processed images and metric values. | Support image processing and prototype fusion rules supplied by the researcher. | Commercial | Save MATLAB/toolbox versions and scripts; identify any additional transform or fusion-metric code and its license. |
| Training | PyTorch | Tensors and model code; weights and predictions. | Implement the chosen fusion architecture, losses, training and inference. | BSD-3-Clause | Save code revision, environment, model configuration, checkpoint hash, seeds, device and determinism settings. |
| Training | PyTorch Lightning | PyTorch models and data modules; checkpoints and logs. | Organize training loops and distributed execution. | Apache 2.0 | Save Trainer settings, callbacks, precision, strategy, resume state and data-loader configuration. |
| Training | TensorFlow / Keras | Tensors and model definitions; saved models and predictions. | Provide an alternative framework for a specified fusion model. | Apache 2.0 | Save architecture, weights, preprocessing, dependency versions, training settings and export signature. |
| Metrics | scikit-image | Source/output arrays; PSNR, SSIM and other implemented metrics. | Compute specified image-quality measures with an explicit reference convention. | BSD-3-Clause; bundled exceptions | Save function/version, data range, window settings, channel handling, masks and per-case values. |
| Metrics | TorchMetrics | Prediction/target tensors; metric states and summaries. | Evaluate supported image or downstream-task metrics within tensor workflows. | Apache 2.0 | Save exact metric class, arguments, reduction and distributed aggregation; verify any custom fusion metric separately. |
| Tracking | TensorBoard | Event logs; scalar curves and image summaries. | Track training and inspect corresponding source/output samples. | Apache 2.0 | Archive event files with run identifiers and configurations; dashboards do not replace data manifests or scripts. |
| Export | ONNX | Supported model graphs; portable graph files. | Exchange a trained fusion model between compatible runtimes. | Apache 2.0 | Record exporter/opset, input names and shapes; check output agreement against the source framework. |
| Inference | TensorRT | Supported models; optimized inference engines. | Optimize inference on supported NVIDIA GPUs. | NVIDIA SDK terms; OSS parts Apache 2.0 | Save runtime/hardware versions, precision, shape profiles and calibration data; measure export-related output changes. |
| Inference | OpenVINO | Supported models; converted models and runtime outputs. | Execute and optimize inference on supported hardware. | Apache 2.0 | Save conversion options, device, precision and runtime version; verify outputs and measure complete-pipeline latency. |
| Packaging | MONAI Deploy App SDK | Application operators and models; packaged applications. | Connect configured image readers, inference and output writers. | Apache 2.0 | Save application graph, package version, series-selection rules, metadata mapping and end-to-end checks. |
| Packaging | Docker Engine | Build recipes and dependencies; container images. | Package the selected preprocessing, inference and evaluation environment. | Apache 2.0; Desktop terms separate | Archive Dockerfile, dependency locks, image digest, mounts, command and host/GPU details; containers do not fix missing data or protocols. |
